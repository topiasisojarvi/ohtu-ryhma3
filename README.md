## Definition of done:

- ominaisuus on pilkottu taskeiksi sprintin backlogille ja sille on kirjattu hyväksymiskriteerit
- ominaisuus on ohjelmoitu
- ominaisuudelle on kirjoitettu yksikkötestit
- ominaisuus täyttää sille asetetut hyväksymiskriteerit
- kaikki yksikkötestit menevät läpi GitHub Actionssissa
- Asennus- ja käyttöohjeet on päivitetty
- ominaisuus on integroitu osaksi muuta ohjelmistoa
- ominaisuuden taskit on merkitty valmiiksi sprintin backlogille

## Sovelluksen asennus ja käyttöohjeet

Ohjelmisto voidaan kopioida paikalliselle tietokoneelle tästä repositoriosta.
Toimiakseen tietokoneella tulee olla asennettuna .NET 11.0

Sovellus ajetaan komentoriviltä sovelluksen juurihakemistossa komennolla "dotnet run"
Käynnistyttyään sovellus antaa ohjeet mahdollisista toimenpiteistä:

- L = lue lähteet
- Enter = lisää lähde
- P = poista lähde
